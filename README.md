# fast-typer
Test typing speed, accuracy and words per minute (WPM).

It's a minimalistic browser typing speed test, built with HTML, CSS and JavaScript.

Inspired by Monkeytype, this project is just me practicing web development while building a typing test from scratch.

## Features
- Randomly generated word sequences ranging from 10-15 words
- Three visible rows
- Dynamic test generation based on available screen width
- Character highlighting for correct and incorrect input
- Blinking cursor
- Prevention of duplicated words during test
- Protection against deleting correctly typed words

## Technologies
- HTML 
- CSS
- JavaScript

## Getting Started
1. Clone the repository
```bash
git clone https://github.com/Andreas528/fast-typer
cd fast-typer
```
2. Open the project folder
3. Open index.html in your browser

No additional dependencies or installation required.
